# Offline Transit App

This is an application designed to provide access to winnipeg transit bus arrival times without the need for wifi or data.

## Usage

You will need to obtain a Winnipeg Transit API key.
[Winnipeg Transit API](https://api.winnipegtransit.com)

And create a file named `apikeys.properties` at the root level of the project with your api key inside like so:
```properties
TRANSIT_API_KEY = "API_KEY_HERE"
```
